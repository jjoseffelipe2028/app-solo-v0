# 📲 Como instalar o App Solo

Para instalar no celular, o app precisa estar num endereço **https** na internet. A hospedagem é grátis pelo **GitHub Pages**. Depois de instalado, ele funciona **sem internet**.

## Passo 1 (José, uma vez só): colocar no ar
> ⚠️ Isso deixa o app **público** na internet (qualquer um com o link abre). Não tem dado pessoal: o laudo fica só no aparelho de quem usa. O José decide se publica.

1. No GitHub, crie um repositório **público** chamado `app-solo-v0`, **vazio** (sem README).
2. Avise a 001: ela sobe os arquivos (commit + push).
3. No repositório: **Settings → Pages → Branch: `main` / `(root)` → Save**.
4. Em 1 a 2 minutos o app fica em: `https://jjoseffelipe2028.github.io/app-solo-v0/`

## Passo 2: instalar no celular (Android)
1. Abra o link no **Chrome**.
2. Toque em **"📲 Instalar no aparelho"** no topo do app. Se não aparecer, use o menu **⋮ → Instalar app** (ou "Adicionar à tela inicial").
3. Pronto: o ícone 🌱 **App Solo** aparece na tela do celular.

**iPhone:** abra no **Safari** → botão **Compartilhar** → **Adicionar à Tela de Início**.

## Passo 3: instalar no PC (Windows)
1. Abra o link no **Edge** ou no **Chrome**.
2. Clique em **"📲 Instalar no aparelho"**, ou no ícone de instalar na barra de endereço.
3. O App Solo vira um programa com ícone no menu Iniciar.

## Testar sem internet
Depois de instalado, ligue o **modo avião** e abra o app: ele tem que abrir normal, com as contas.
